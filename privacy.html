Privacy Policy

GTA VI Clips · Effective date: 7 November 2026

1. Who we are

GTA VI Clips is an independent YouTube channel (youtube.com/@GTA.VI.Clip.s). The GTA VI Clips application is a private tool that the channel owner uses to publish the channel's own videos. This policy explains what data the application uses and why.

2. Who uses the application

Only the channel owner signs in to the application. It is not offered to the public, and it does not access the accounts, channels or data of any other person.

3. Google user data we access

The application uses the YouTube API Services with a single permission:

  • youtube.upload, to upload videos to the owner's YouTube channel and to set their title, description, tags and privacy status.

It does not read your email, contacts, files, watch history, subscribers, comments or any other Google account data.

4. How we use the data

The permission is used for one purpose only: publishing videos produced by GTA VI Clips to the owner's channel after the owner has approved each video. We do not use Google user data for advertising, profiling or any purpose other than this.

5. How we store and protect the data

  • The OAuth access and refresh tokens issued by Google are stored only on the owner's personal computer, in a local file that is not shared or uploaded anywhere.
  • We keep a local record of the videos we upload (video ID, link and date) so the same video is not uploaded twice.
  • We do not sell, rent or share Google user data with anyone. No Google user data is transferred to third parties.

6. Retention and deletion

The tokens are kept only while the application is in use. You can revoke the application's access at any time from your Google Account permissions page: security.google.com/settings/security/permissions. Once access is revoked, the stored tokens stop working, and the owner deletes them from the computer. To ask for deletion of any data, write to the contact address below.

7. YouTube API Services

The application uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. How Google handles your data is described in the Google Privacy Policy.

8. Limited Use

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

9. Visitors to this website

This website does not use cookies, analytics or tracking, and it does not collect personal data from visitors.

10. Changes to this policy

If this policy changes, we will update it on this page and change the effective date above.
